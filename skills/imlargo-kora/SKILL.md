# Kora

> Builds on `imlargo` and `imlargo-projects`, which holds the project lifecycle, specs, backlog and delivery. This skill adds the client side: positioning, selling, proposals and terms. Prices are imlargo's: never write a number imlargo didn't give; leave it marked.

## What Kora Is

A product and technology studio: it thinks with the client about what to build, designs it and builds it. Criterion and execution in the same team.

| | Does | Kora |
|---|---|---|
| Consultancy | Advises and leaves without building | Decides with the client and builds it |
| Software factory | Builds whatever it's told | Questions the premise first; may recommend not building |
| Agency | Makes it look good | Builds systems that run the operation unsupervised |

Never describe Kora as a consultancy, a factory or "your strategic ally". → [positioning](references/positioning.md)

## Two Ways imlargo Works

| | Kora studio | Independent senior engineer |

| Who signs | Kora | imlargo (Juan Carlos), as a professional services provider |

Which model applies is imlargo's decision, recorded in the project's `context.md`. If it isn't there, ask. → [engagement-models](references/engagement-models.md)

## Rules for Every Client

- **Define before building.** No construction without the diagnosis or analysis phase, even when the client insists. A definition error costs a conversation; the same error mid-build costs months.
- **Say no.** If what they ask isn't what they need, or an existing tool already solves it, say so in writing.
- **Visible progress.** Working software in production every week, deploy pipeline from day one, not progress reports.
- **The client owns everything:** code, data, credentials and infrastructure in their name, exportable any time. The system must run and be continued without imlargo.
- **Closed scope, managed changes.** Minor changes are absorbed; anything that widens the frozen scope is documented, estimated and agreed before it's built.
- **The client decides the what and the why; imlargo answers for the how.** The client accepts each deliverable formally.
- **One or two projects at a time.** Present it as the standard, never as a limit.
- **Talk business results, never stack,** to a decision maker who is usually not technical.

## Client-Facing Writing

Plain, direct, with criterion: the senior advisor who also builds. Short sentences, provable claims, a real number over ten adjectives. No buzzwords, hype or emojis. Say what Kora doesn't do as clearly as what it does. Spanish for Colombian clients; run substantial text through `avoid-ai-writing`.
